---
name: setup
description: Connect CodeSpace to a user-selected repository or configure its remote MCP endpoint for ChatGPT on a phone.
---

Ask which repository to use only when the current task does not identify one.
Check `cse --version` and `cse doctor --path <repository>`. Version 3.0.0 is required.
If the index is absent, initialize it with `cse init --path <repository>`.
Use the packaged `scripts/setup.mjs --workspace <absolute path> --binary <executable>`
to save local configuration. Start read-only; enable writes only when the user
requests task/checkpoint updates. Never put credentials into manifests or chat.

The local process works in a desktop host. For ChatGPT web/mobile, use the remote
package generated by the repository's `scripts/package_plugin.py --remote-url`
against a verified, authenticated HTTPS `/mcp` endpoint. A ZIP upload does not
deploy that endpoint or authenticate the user's ChatGPT account. See the shipped
`docs/CHATGPT.md` in the source repository for deployment and phone acceptance tests.
